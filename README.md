# Responsive Profile Card

A simple and responsive profile card created using **HTML and CSS**.

## 📌 About the Project

This project is a basic profile card designed to practice HTML and CSS.
It features a profile image, personal information, and a responsive layout that adapts to different screen sizes.

- HTML5
- CSS3
